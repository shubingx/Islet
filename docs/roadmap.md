# 專案進度與路線

## 功能狀態

| 模組 | 能做什麼 | 狀態 |
| --- | --- | --- |
| 🕐 日期時間 | 收合時顯示時間；展開顯示日期、星期 | ✅ 可用 |
| 🏠 首頁 | 不放卡片，只顯示你選的背景：自選圖片、純色或目前歌曲的封面，可調填滿方式、暗化與模糊 | ✅ 可用 |
| 🎵 音樂 | 歌名、封面、進度條、播放／暫停、上下首、拖曳進度；支援 Spotify 桌面版、瀏覽器裡的 YouTube／YouTube Music 等 | ✅ 可用 |
| 💬 通知 | 讀取 Windows 通知中心，**只留社群 App**（LINE、Discord、Messenger、Telegram 等）；瀏覽器通知只放行 Instagram、Facebook、X 網頁版，並標示來源網站；顯示 App 真實圖示，點擊開啟原 App | ✅ 可用（需允許通知存取） |
| ⏱️ 計時器 | 倒數（1／5／10／25 分預設、±1 分）與碼錶，時間到會在島上提示 | ✅ 可用 |
| 📊 效能 | CPU、記憶體、GPU、磁碟四個環形儀表，加上網路上傳／下載速度曲線；只在該頁顯示時取樣 | ✅ 可用 |
| ⚙️ 設定 | 獨立設定視窗：開機自動啟動、展開／收合延遲、首頁背景、分頁開關與排序；變更即時套用 | ✅ 可用 |
| 🌙 模式 | 勿擾、專注、自訂模式（顯示哪些模組、通知白名單、主題） | 🚧 可切換，勿擾可用，自訂規則尚未完成 |
| ✅ 待辦提醒 | 新增、完成、到期提醒；收合時顯示下一項 | 🚧 可新增，尚未存檔與到期提醒 |
| 🧩 自訂腳本 | 用 JavaScript 新增卡片、發通知、定時觸發、回應點擊 | 📋 規劃中 |
| 🎨 主題 | 深色、淺色、跟隨系統，可匯入自訂主題 | 🚧 目前只有深色 |

圖例：✅ 可用　🚧 進行中　📋 規劃中　💭 構想

## 開發路線

| 階段 | 內容 | 狀態 |
| --- | --- | --- |
| 0. 技術驗證 | 透明置頂膠囊視窗、彈簧動畫、通知監聽 | ✅ 完成（打包後的授權流程待驗證） |
| 1. MVP | 收合與展開、日期時間、音樂控制、計時器、效能頁、首頁背景、設定視窗、開機啟動、App 圖示 | ✅ 大致完成；全螢幕自動隱藏、系統匣未做 |
| 2. 通知與模式 | 通知列表、社群過濾、真實 App 圖示、勿擾 ✅；分組、自訂模式規則 🚧 | 🚧 進行中 |
| 3. 待辦與提醒 | 待辦清單、到期提醒、資料存檔 | 🚧 只有清單 |
| 4. 腳本系統 | manifest、權限確認、API、範例腳本、管理頁 | 📋 |
| 5. 打磨與發佈 | 多螢幕與高 DPI、主題匯入、自動更新、安裝程式 | 📋 |
| 之後 | 桌寵外觀模組、Python 等外部程序腳本 | 💭 |

## 測試版已知限制

- 待辦重開即清空；通知只保留本次執行期間收到的。
- 免安裝執行時，部分 Windows 版本無法讀取通知（會顯示「需要打包版」），要等安裝檔／套件身分完成。
- 未實作全螢幕自動隱藏、多螢幕選擇、系統匣、淺色主題。
- 點擊展開的島會取走目前視窗焦點（否則待辦輸入框無法打字），正式版會改為輸入時才取得焦點。
- 收合與提示狀態為點擊穿透，只有展開時才接收點擊。
- 圖示使用 Windows 內建的 Segoe Fluent Icons／Segoe MDL2 Assets 字型。
